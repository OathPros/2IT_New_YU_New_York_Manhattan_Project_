# Detailed York IT service catalogue

## Discoverability
- 75 concrete offerings, not 22 large buckets
- 22 existing categories retained as navigation groups and browse-by-category pages
- Each offering has an independently addressable URL, description, supported audience, action and related knowledge
- The homepage displays all offerings by default; filter by audience, category and name without reloading
- Each card displays related knowledge and an access or request action before the user opens its page
- The offering page displays all knowledge explicitly assigned to that offering and shows related offerings in its service category

## NEXUS model
- Service families map to governed Service entities
- Each detailed service is an Offering linked by HAS_OFFERING to its parent Service
- Knowledge references are linked to the specific Offering through HAS_KNOWLEDGE
- Each offering retains source URLs and is marked not_validated until service owner review
- Source-specific article drafts remain distinct from curated vendor links; no claims of production validation
