# Procedure

Inventory existing routes, tasks, audiences and content; preserve meaningful deep links. Identify top tasks and failure paths. Map intent to entry point, action, feedback and next step. Remove unnecessary decisions and duplicate navigation. Separate information model from presentation. Prototype representative journeys with realistic content and edge cases. Specify route/state behavior, back navigation, empty/error/loading behavior and accessible alternatives. Validate with task scenarios rather than number of components.
