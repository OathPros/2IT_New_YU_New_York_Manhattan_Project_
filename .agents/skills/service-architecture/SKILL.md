# Procedure

Inspect the actual schema and authoritative sources. Distinguish service capability, offering, operation, knowledge, audience, dependency, team and source only where useful. Reuse stable identifiers; avoid parallel schemas. Define relations, applicability, validation and provenance; test orphan references and duplicate identities. Compose offering pages from real relationships and action intent. Keep support and knowledge contextual but independently addressable. Validate eligibility and security procedures against authoritative material; mark gaps. Expose explicit future integration seams without faking transactions or AI. Deliver data/route migration map and representative journey tests.
