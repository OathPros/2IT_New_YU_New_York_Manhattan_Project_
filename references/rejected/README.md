# Rejected patterns

Evidence is in `.devkit/artifacts/` (gitignored): `baseline/` for the original app, `concepts/` for the three directions and `slice-3/` before critique

| Pattern | Where seen | Why rejected | Preferred alternative |
| --- | --- | --- | --- |
| Repeated rounded card grids for services | Baseline home, concept C | Visual noise, every item weighted equally, weak scanning | Index rows with label column and hairlines |
| Duplicate student and employee pages | Baseline services | Divergent content, users must choose a page before a task | One service with audience filters and a choice step |
| Dark console theme | Concept B | Low warmth for a public support site, harder long-form reading | B's palette and rail translated to the light theme |
| Red action on every catalogue row | Slice 3 catalogue | Diluted primary emphasis | Ink underlined links; red reserved for the primary action |
| Generic link names such as "Source 1" | Slice 3 reader | Fails WCAG 2.4.4 link purpose | Name the destination by host and path |
| Primary action below escalation on mobile | Slice 3 task page | Users scroll past help before the action | Compact "Start here" at the top under 960px |
| Legacy clip-art and live chat text inline | Slice 3 help page | Inconsistent and makes a false availability claim | Collapsed preserved copy with a disclaimer |
